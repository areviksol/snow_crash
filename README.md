# Snow Crash Walkthrough

This repository contains notes and write-ups for the **42 Snow Crash** security project, from `level00` to `level14`.

## Repository Structure

- `level00` ... `level14`: one folder per level
- `resources/README.md` inside each level: solution notes and commands used

## Getting Started

1. Connect to the Snow Crash VM.
2. Start from `level00`.
3. Read the corresponding level write-up in this repository.
4. Reproduce the steps and validate the result with `getflag`.
5. Use the retrieved token to move to the next level.

## Example Connection

```bash
ssh level00@localhost -p 4242
```

## Notes

- This project is for educational and CTF practice purposes.
- Keep your own notes while solving; understanding the process matters more than just collecting tokens.
